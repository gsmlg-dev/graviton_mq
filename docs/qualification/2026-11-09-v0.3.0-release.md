# v0.3.0 release qualification — 2026-11-09

Source verification passed locally on Linux and in hosted CI, and the public
publication below was verified.

## Review baseline

The 2026-11-08 repository review ran at `781876f` (v0.2.1 plus its
publication record). It reported two High findings (AMQP zero-width array
amplification; WAL lifetime cap) and eight Medium findings (MQTT post-CONNECT
packets, MQTT takeover stale session, AMQP Begin windows, AMQP in-flight frames
after Detach, AMQP broker blast radius/polling, WAL recovery, MQTT client
checkpoint/tick, release workflow). Each code finding received a regression
test that failed before its repair.

## Source changes

- `696dca0` — repairs for all High and Medium findings and documentation.
- `438acf4` — follow-up: an unknown enqueue outcome no longer fences the queue.
  Hosted CI run 42500780476 for `696dca0` passed its `checks` job, but its
  independent-peer job had one failure: the Proton test "failed
  synchronization closes publication without Proton Accepted" observed the
  queue as `:unavailable` instead of `storage: :failed`. Enqueue holds no
  lease, so the repair keeps only the Connection close without disposition.
  This failure is recorded, not relabeled.
- The release-preparation commit sets `VERSION` to `0.3.0` and adds these
  records.
