## Independent peer

Mosquitto **2.1.2**, broker and `mosquitto_pub`/`mosquitto_sub`, selected from
immutable Nix source `6bf80a7m11xpxdh0qi5k83721lqxk11s-source`, nar hash
`sha256-bu1QxmXKmPuvBLN7bHP355OV9Qo13x9WCiRDH62CqRM=`. The helper rejects a
different version. Each test uses its own ephemeral loopback listener,
`persistence false`, `max_qos 1`, and explicit anonymous/password/ACL/TLS
configuration for that case. Certificates and credentials are synthetic and
temporary. Peers, proxy connections and timers are cleaned up after tests.

```sh
GRAVITON_MOSQUITTO_BIN=/absolute/path/to/mosquitto-2.1.2/bin/mosquitto \
  mix test apps/graviton_mq_client/test/mqtt_mosquitto_test.exs \
    apps/graviton_mq_client/test/mqtt_session_mosquitto_test.exs --trace --seed 0
```

Result: 11 tests, zero failures. TLS rejection notices in the negative cases
are expected evidence. Without the explicit binary, `:interop` tests are
excluded and the ordinary suite cannot establish peer qualification.

The PUBACK-loss proxy drops the first actual broker PUBACK; it does not
fabricate CONNACK/PUBACK or replace the peer. The same Mosquitto process
remains alive. This exercises network reconnection with memory state; it is
not broker disk recovery, client process recovery, or exactly-once processing.

## Limits and next entry

G1 provides QoS0/1, bounded memory session state and TCP/TLS. QoS2, enhanced
authentication, topic aliases and persistent recovery are unavailable;
received use follows explicit rejection paths. MQTT3.1.1 remains codec-only.
Full mandatory/conditional MQTT5 semantics and selected-profile conformance
need G5/G7 evidence. MQTT acknowledgements do not imply host processing or
disk durability. Crash/VM restart recovery is NOT RUN and belongs to G6.

G2 starts from the approved embedding design: pure topics/session/retained/
Will/expiry behavior, instance-owned memory responsibility, bounded host API,
explicit fail-closed authn/authz, TCP/TLS and real two-instance isolation.
Independent Mosquitto/Paho clients must qualify network behavior before a
broker role is marked implemented. AMQP network roles remain unimplemented.
