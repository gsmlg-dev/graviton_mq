# S2 — AMQP 1.0 SASL (ANONYMOUS, PLAIN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the AMQP 1.0 SASL security layer (Part 5 §5.3, mechanisms ANONYMOUS/RFC 4505 and PLAIN/RFC 4616) to our client (SASL client) and broker (SASL server), with a pure codec and negotiation machine, a host authentication callback, principal propagation into `authorize/3`, privacy, bounds and independent-peer evidence.

**Architecture:** `graviton_mq_amqp10` gains a SASL frame layer (`Codec.ProtocolHeader.recognize/2`, `Codec.Frame` `types:` option, `Codec.Stream` header re-entry, `Codec.SASL`) and a pure, generation-fenced `SASL.Machine` (server and client roles) that runs **before** the unchanged `Endpoint`. Shells (`Runtime.AMQP10.Connection`, `Client.AMQP10`) step the Machine first and step the Endpoint `:start` only after `{:start_endpoint, _}`. The broker always waits for the client header (owner Q7). Authentication runs in tasks under a new `:sasl_tasks` Task.Supervisor, started by a new policy-holding `Authenticator` process so that host auth options are never published in the Listener's readable ETS connection spec.

**Tech Stack:** Elixir 1.18.4 / OTP 28 umbrella (`.tool-versions`), ExUnit, raw `:gen_tcp` peers for local evidence, Qpid Proton 0.40.0 and Artemis 2.41.0 for CI-only independent evidence (`scripts/interop/run.py`).

**Input spec:** `docs/superpowers/specs/2026-11-12-s2-amqp-sasl-design.md` (approved 2026-11-12; Q7 = always defer the broker header; all other §10 recommendations accepted).

## Decisions made while planning (deviations/clarifications of the spec)

- **D1 Policy holder.** `Listener` publishes the Connection spec in a `:protected` ETS table and explicitly allowlists keys so that "future auth or credential options are never published". The Connection therefore never receives `{module, options}`. A new `GravitonMQ.Runtime.AMQP10.Authenticator` process (sensitive, redacted) holds the policy and starts each callback under `:sasl_tasks`. Credentials pass only through this process (never the Broker/Manager), matching spec §5.2's intent.
- **D2 Machine API.** `new(role: :server, ...)` also takes `authenticate: boolean` (true for `{module, options}`), needed for "ANONYMOUS without callback ⇒ ok". The auth reference is `{:sasl_auth, n}` (pure, no `make_ref`). `{:auth_result, ref, :ok | {:error, code}}` — the principal stays in the shell (spec: machine never stores it). Extra informational effect `{:outcome, code}` lets the broker count `sasl_failures` without parsing bytes.
- **D3 Stream shape.** Instead of a tuple phase, `Codec.Stream` gains fields `accept` and `frame_type` (phase stays `:protocol_header | :frames`); behaviour is identical to spec §4.1.
- **D4 Header acceptance.** Both SASL-capable shells read headers with `accept: [0, 3]`; the Machine decides (`:sasl_not_offered`, `:sasl_required`, `:sasl_not_supported`). `recognize/1` keeps its historical results.
- **D5 Pipelined header.** After a valid sasl-init the server stream immediately expects `AMQP 0 1 0 0`. A peer's header pipelined before the outcome is retained and consumed after `ok`; any further SASL frame then fails header recognition and closes without an outcome (same result as spec's "second sasl-init ⇒ close").
- **D6 Close drain.** SE-5.1-b003-s01's read-until-EOF is SHOULD-level and, as for TR-2.2-b003-s02 today, not implemented: shells flush the final bytes (header or outcome) and then close.
- **D7 Plain inspect.** `Inspect` for `SASL.Plain` redacts username, authzid and password (spec §5.3 forbids logging usernames too).
- **D8 PLAIN needs a callback.** Broker config rejects `"PLAIN"` under `auth: :anonymous` (`:plain_requires_authentication`) — there is nothing to check the password against.
- **D9 Client oversize credentials.** RFC 4616 allows 767-octet PLAIN messages, but a SASL frame is ≤ 512 octets. Client config rejects credentials whose sasl-init would not fit (`:invalid_options`); a password provider returning such a value disconnects with `:invalid_sasl_credentials`.
- **D10 Inventory.** The repository has no inventory extractor script (only the generated `docs/qualification/2026-10-30-amqp10-requirement-inventory.{md,json}`). C4 adds the spec's provisional `SE-` rows by hand with the Part 5 source hash; IDs stay marked provisional.
- **D11 Artemis Q9 fallback.** If enabling `security-enabled=true` breaks existing no-SASL suites in CI, the second-instance fallback is a structural change to shared `run.py`; C2 stops and hands the CI evidence to the owner/coordinator instead of improvising it.
- **D13 Callback deadline.** The Connection bounds each callback by `auth_timeout` (≤ 3 s, `sys-temp` on expiry). The spec's "capped by the remaining `sasl_timeout`" is enforced by the negotiation deadline itself: if it fires first the Machine cancels the callback and closes without an outcome.
- **D12 Known risk (unchanged by S2).** `HellHandoff` documents that the first `{:tcp, raw, data}` may theoretically precede `{:accepted, raw}` and is dropped. With header deferral a dropped client header leaves the connection waiting for `sasl_timeout` (previously the Open deadline). Not addressed here.

```elixir
defmodule GravitonMQ.AMQP10.Codec.ProtocolHeader do
  @moduledoc """
  Recognizes fixed AMQP 1.0 protocol headers without negotiating a protocol.

  `recognize/1` accepts only `AMQP 0 1 0 0` and keeps its historical results.
  `recognize/2` takes the protocol IDs a caller currently accepts — `[0]`,
  `[3]` or `[0, 3]` — where ID 3 is the SASL layer header `AMQP 3 1 0 0`
  (Part 5 §5.3). Recognition never selects or negotiates a layer.
  """

  alias GravitonMQ.AMQP10.Codec
  alias GravitonMQ.AMQP10.Codec.Error

  @enforce_keys [:protocol_id, :major, :minor, :revision]
  defstruct [:protocol_id, :major, :minor, :revision]

  @type t :: %__MODULE__{
          protocol_id: 0..255,
          major: 0..255,
          minor: 0..255,
          revision: 0..255
        }
  @type accept :: [0 | 3]

  @accepts [[0], [3], [0, 3], [3, 0]]

  @spec accept?(term()) :: boolean()
  def accept?(accept), do: accept in @accepts

  @spec recognize(binary()) :: Codec.decode_result(t())
  def recognize(input), do: recognize(input, [0])

  @spec recognize(binary(), accept()) :: Codec.decode_result(t())
  def recognize(input, accept) when is_binary(input) and accept in @accepts do
    case input do
      <<"AMQP", protocol_id, major, minor, revision, rest::binary>> ->
        protocol_header(protocol_id, major, minor, revision, rest, accept)

      header when byte_size(header) < 4 ->
        if header == binary_part("AMQP", 0, byte_size(header)),
          do: {:more, 8 - byte_size(header)},
          else: magic_error()

      <<"AMQP", rest::binary>> ->
        {:more, 4 - byte_size(rest)}

      _other ->
        magic_error()
    end
  end

  def recognize(_input, _accept),
    do: {:error, Error.new(:protocol_header, :invalid_value, :invalid_accept)}

  defp protocol_header(protocol_id, 1, 0, 0, rest, accept) when protocol_id in [0, 3] do
    if protocol_id in accept,
      do: {:ok, %__MODULE__{protocol_id: protocol_id, major: 1, minor: 0, revision: 0}, rest},
      else: not_accepted(protocol_id)
  end

  defp protocol_header(protocol_id, major, minor, revision, _rest, accept)
       when protocol_id in [0, 3] do
    if protocol_id in accept,
      do: version_error(protocol_id, major, minor, revision),
      else: not_accepted(protocol_id)
  end

  defp protocol_header(protocol_id, _major, _minor, _revision, _rest, _accept),
    do: unsupported_protocol_id(protocol_id)

  defp not_accepted(3) do
    {:error,
     Error.new(:protocol_header, :unsupported, :sasl_not_supported,
       offset: 4,
       details: %{protocol_id: 3}
     )}
  end

  defp not_accepted(protocol_id), do: unsupported_protocol_id(protocol_id)

  defp unsupported_protocol_id(protocol_id) do
    {:error,
     Error.new(:protocol_header, :unsupported, :unsupported_protocol_id,
       offset: 4,
       details: %{protocol_id: protocol_id}
     )}
  end

  defp version_error(protocol_id, major, minor, revision) do
    {:error,
     Error.new(:protocol_header, :unsupported, :unsupported_version,
       offset: 5,
       details: %{protocol_id: protocol_id, major: major, minor: minor, revision: revision}
     )}
  end

  defp magic_error do
    {:error,
     Error.new(:protocol_header, :malformed, :invalid_protocol_magic, offset: 0, details: %{})}
  end
end
```

```elixir
defmodule GravitonMQ.AMQP10.Codec.Frame do
  @moduledoc """
  Encodes and decodes AMQP 1.0 and SASL frame envelopes without interpreting their bodies.

  The codec is process-free and preserves the extended header and opaque body
  exactly for later protocol layers. Encoding validates the supplied size and
  data offset against the actual bytes before allocating the wire envelope.

  The `types:` option selects the expected layer: `[:amqp]` (default) or
  `[:sasl]`. A SASL frame (type `0x01`, Part 5 §5.3.1) is bounded by
  MIN-MAX-FRAME-SIZE (512 octets) in both directions regardless of
  `Limits.max_frame_size`. Its channel bytes and extended header are ignored
  data on decode; encoding requires channel 0 and data offset 2.
  """

  alias GravitonMQ.AMQP10.Codec
  alias GravitonMQ.AMQP10.Codec.Error
  alias GravitonMQ.AMQP10.Codec.Limits
  alias GravitonMQ.AMQP10.Frame, as: AMQPFrame

  @fixed_header_size 8
  @max_wire_frame_size 0xFFFF_FFFF
  @max_data_offset_words 255
  @sasl_max_frame_size 512

  @spec decode(binary()) :: Codec.decode_result(AMQPFrame.t())
  @spec decode(binary(), Limits.t()) :: Codec.decode_result(AMQPFrame.t())
  @spec decode(binary(), Limits.t(), keyword()) :: Codec.decode_result(AMQPFrame.t())
  def decode(input, limits \\ Limits.default(), options \\ []) when is_binary(input) do
    with {:ok, limits} <- Limits.validate(limits, :frame_decode),
         {:ok, type} <- frame_type(options, :frame_decode) do
      decode_frame(input, limits, type)
    end
  end

  @spec encode(AMQPFrame.t()) :: Codec.encode_result()
  @spec encode(AMQPFrame.t(), Limits.t()) :: Codec.encode_result()
  @spec encode(AMQPFrame.t(), Limits.t(), keyword()) :: Codec.encode_result()
  def encode(frame, limits \\ Limits.default(), options \\ []) do
    with {:ok, limits} <- Limits.validate(limits, :frame_encode),
         {:ok, type} <- frame_type(options, :frame_encode) do
      encode_frame(frame, limits, type)
    end
  end

  defp frame_type(options, operation) do
    case Keyword.get(options, :types, [:amqp]) do
      [:amqp] -> {:ok, :amqp}
      [:sasl] -> {:ok, :sasl}
      _other -> {:error, Error.new(operation, :invalid_value, :invalid_frame_types)}
    end
  end

  defp encode_frame(
         %AMQPFrame{
           declared_size: declared_size,
           data_offset_words: data_offset_words,
           type: _,
           channel: channel,
           extended_header: extended_header,
           body: body
         } = frame,
         limits,
         type
       ) do
    cond do
      not integer_between?(declared_size, @fixed_header_size, @max_wire_frame_size) ->
        encode_error(:invalid_value, :invalid_declared_size)

      not integer_between?(data_offset_words, 2, @max_data_offset_words) ->
        encode_error(:invalid_value, :invalid_data_offset)

      not integer_between?(channel, 0, 65_535) ->
        encode_error(:invalid_value, :invalid_channel)

      not is_binary(extended_header) ->
        encode_error(:invalid_value, :invalid_extended_header)

      not is_binary(body) ->
        encode_error(:invalid_value, :invalid_body)

      true ->
        encode_envelope(frame, limits, type)
    end
  end

  defp encode_frame(_frame, _limits, _type), do: encode_error(:invalid_value, :invalid_frame)

  defp encode_envelope(frame, limits, type) do
    header_size = @fixed_header_size + byte_size(frame.extended_header)
    size = header_size + byte_size(frame.body)

    cond do
      rem(header_size, 4) != 0 ->
        encode_error(:invalid_value, :unaligned_extended_header)

      div(header_size, 4) > @max_data_offset_words ->
        encode_error(:limit_exceeded, :data_offset_limit)

      frame.data_offset_words * 4 != header_size ->
        encode_error(:invalid_value, :data_offset_mismatch)

      size > @max_wire_frame_size or size > limits.max_frame_size ->
        encode_error(:limit_exceeded, :frame_size_limit)

      frame.declared_size != size ->
        encode_error(:invalid_value, :declared_size_mismatch)

      frame.type == :sasl and type == :amqp ->
        encode_error(:unsupported, :sasl_frame_not_supported)

      frame.type != type ->
        encode_error(:invalid_value, :invalid_frame_type)

      type == :sasl and (frame.channel != 0 or frame.data_offset_words != 2) ->
        encode_error(:invalid_value, :invalid_sasl_envelope)

      type == :sasl and size > @sasl_max_frame_size ->
        encode_error(:limit_exceeded, :frame_size_limit)

      true ->
        {:ok,
         <<size::32, frame.data_offset_words, type_code(type), frame.channel::16,
           frame.extended_header::binary, frame.body::binary>>}
    end
  end

  defp type_code(:amqp), do: 0
  defp type_code(:sasl), do: 1

  defp integer_between?(value, minimum, maximum),
    do: is_integer(value) and value >= minimum and value <= maximum

  defp encode_error(class, reason), do: {:error, Error.new(:frame_encode, class, reason)}

  defp decode_frame(input, _limits, _type) when byte_size(input) < @fixed_header_size do
    {:more, @fixed_header_size - byte_size(input)}
  end

  defp decode_frame(
         <<size::32, data_offset_words, type_code, channel::16, _rest::binary>> = input,
         limits,
         type
       ) do
    with :ok <- validate_size(size),
         :ok <- validate_data_offset(data_offset_words),
         :ok <- validate_frame_boundary(size, data_offset_words),
         :ok <- validate_frame_limit(size, maximum_frame_size(type, limits)),
         {:ok, type} <- validate_type(type_code, type) do
      decode_complete_frame(input, size, data_offset_words, channel, type)
    end
  end

  defp maximum_frame_size(:sasl, _limits), do: @sasl_max_frame_size
  defp maximum_frame_size(:amqp, limits), do: limits.max_frame_size

  defp decode_complete_frame(input, size, _data_offset_words, _channel, _type)
       when byte_size(input) < size do
    {:more, size - byte_size(input)}
  end

  defp decode_complete_frame(input, size, data_offset_words, channel, type) do
    data_offset = data_offset_words * 4
    extended_header_size = data_offset - @fixed_header_size
    body_size = size - data_offset

    <<_fixed_header::binary-size(@fixed_header_size),
      extended_header::binary-size(extended_header_size), body::binary-size(body_size),
      rest::binary>> = input

    {:ok,
     %AMQPFrame{
       declared_size: size,
       data_offset_words: data_offset_words,
       type: type,
       channel: channel,
       extended_header: extended_header,
       body: body
     }, rest}
  end

  defp validate_size(size) when size >= @fixed_header_size, do: :ok

  defp validate_size(_size) do
    {:error, Error.new(:frame_decode, :malformed, :frame_too_small, offset: 0)}
  end

  defp validate_data_offset(data_offset_words) when data_offset_words >= 2, do: :ok

  defp validate_data_offset(_data_offset_words) do
    {:error, Error.new(:frame_decode, :malformed, :data_offset_too_small, offset: 4)}
  end

  defp validate_frame_boundary(size, data_offset_words) when data_offset_words * 4 <= size,
    do: :ok

  defp validate_frame_boundary(_size, _data_offset_words) do
    {:error, Error.new(:frame_decode, :malformed, :data_offset_beyond_frame, offset: 4)}
  end

  defp validate_frame_limit(size, maximum) when size <= maximum, do: :ok

  defp validate_frame_limit(_size, _maximum) do
    {:error, Error.new(:frame_decode, :limit_exceeded, :frame_size_limit, offset: 0)}
  end

  defp validate_type(0, :amqp), do: {:ok, :amqp}
  defp validate_type(1, :sasl), do: {:ok, :sasl}

  defp validate_type(1, :amqp) do
    {:error, Error.new(:frame_decode, :unsupported, :sasl_frame_not_supported, offset: 5)}
  end

  defp validate_type(0, :sasl) do
    {:error, Error.new(:frame_decode, :malformed, :amqp_frame_in_sasl_layer, offset: 5)}
  end

  defp validate_type(_type_code, _type) do
    {:error, Error.new(:frame_decode, :unsupported, :unsupported_frame_type, offset: 5)}
  end
```

```elixir
defmodule GravitonMQ.AMQP10.Codec.Stream do
  @moduledoc """
  Pure incremental AMQP header/frame envelope reader shared by running roles.

  `next/2` yields one opaque envelope and the remaining input. Callers control
  work per turn by deciding when to consume that remainder. Only an incomplete
  envelope is retained, bounded by the configured frame limit (512 octets for
  SASL frames). Coalesced valid frames may collectively exceed that limit
  without enlarging the buffer.

  `new/2` accepts `accept: [0] | [3] | [0, 3]` protocol IDs. A recognized
  SASL header (ID 3) switches the frame phase to SASL frames; after a
  successful sasl-outcome the caller re-enters the header phase with
  `expect_header/2`. Bytes already returned as remaining input are untouched.
  This reader never decodes a performative, SASL body or message and never
  negotiates a layer.
  """

  alias GravitonMQ.AMQP10.Codec.Error
  alias GravitonMQ.AMQP10.Codec.Frame, as: FrameCodec
  alias GravitonMQ.AMQP10.Codec.Limits
  alias GravitonMQ.AMQP10.Codec.ProtocolHeader
  alias GravitonMQ.AMQP10.Frame

  @sasl_buffer 512

  defstruct phase: :protocol_header,
            buffer: <<>>,
            limits: %Limits{},
            accept: [0],
            frame_type: :amqp

  @type t :: %__MODULE__{
          phase: :protocol_header | :frames,
          buffer: binary(),
          limits: Limits.t(),
          accept: ProtocolHeader.accept(),
          frame_type: :amqp | :sasl
        }
  @type item :: {:protocol_header, ProtocolHeader.t()} | {:frame, Frame.t()}

  @spec new(Limits.t(), keyword()) :: {:ok, t()} | {:error, Error.t()}
  def new(limits \\ Limits.default(), options \\ []) do
    accept = Keyword.get(options, :accept, [0])

    with {:ok, limits} <- Limits.validate(limits, :frame_decode) do
      if ProtocolHeader.accept?(accept),
        do: {:ok, %__MODULE__{limits: limits, accept: accept}},
        else: invalid_stream()
    end
  end

  @doc "Re-enter the protocol-header phase after a SASL outcome; refuses a partial frame."
  @spec expect_header(t(), ProtocolHeader.accept()) :: {:ok, t()} | {:error, Error.t()}
  def expect_header(%__MODULE__{phase: :frames, buffer: <<>>} = stream, accept) do
    if ProtocolHeader.accept?(accept),
      do: {:ok, %{stream | phase: :protocol_header, accept: accept, frame_type: :amqp}},
      else: invalid_stream()
  end

  def expect_header(_stream, _accept), do: invalid_stream()

  @spec next(t(), binary()) ::
          {:ok, item(), t(), binary()} | {:more, t()} | {:error, Error.t()}
  def next(stream, input)

  def next(%__MODULE__{phase: phase, buffer: buffer, frame_type: type} = stream, input)
      when phase in [:protocol_header, :frames] and type in [:amqp, :sasl] and
             is_binary(buffer) and is_binary(input) do
    with true <- ProtocolHeader.accept?(stream.accept) || invalid_stream(),
         {:ok, _limits} <- Limits.validate(stream.limits, :frame_decode),
         :ok <- buffer_size(stream, byte_size(buffer)) do
      read_next(stream, input)
    end
  end

  def next(_stream, _input), do: invalid_stream()

  defp read_next(stream, input) do
    case decode_buffer(stream) do
      {:ok, %ProtocolHeader{} = header, rest} ->
        type = if header.protocol_id == 3, do: :sasl, else: :amqp

        {:ok, {:protocol_header, header},
         %{stream | phase: :frames, frame_type: type, buffer: rest}, input}

      {:ok, %Frame{} = frame, rest} ->
        {:ok, {:frame, frame}, %{stream | buffer: rest}, input}

      {:more, _needed} when input == <<>> ->
        {:more, stream}

      {:more, needed} ->
        take = min(needed, byte_size(input))

        with :ok <- buffer_size(stream, byte_size(stream.buffer) + take) do
          <<part::binary-size(take), rest::binary>> = input
          read_next(%{stream | buffer: stream.buffer <> part}, rest)
        end

      {:error, %Error{}} = error ->
        error
    end
  end

  defp decode_buffer(%__MODULE__{phase: :protocol_header, buffer: buffer, accept: accept}),
    do: ProtocolHeader.recognize(buffer, accept)

  defp decode_buffer(%__MODULE__{phase: :frames, buffer: buffer, limits: limits, frame_type: type}),
    do: FrameCodec.decode(buffer, limits, types: [type])

  defp buffer_size(stream, size) do
    maximum =
      case stream do
        %{phase: :protocol_header} -> 8
        %{frame_type: :sasl} -> @sasl_buffer
        %{limits: limits} -> limits.max_frame_size
      end

    if size <= maximum,
      do: :ok,
      else: {:error, Error.new(:frame_decode, :limit_exceeded, :stream_buffer_limit)}
  end

  defp invalid_stream, do: {:error, Error.new(:frame_decode, :invalid_value, :invalid_stream)}
end
```

```elixir
defmodule GravitonMQ.AMQP10.Codec.SASL do
  @moduledoc """
  Pure codec for the five AMQP 1.0 SASL frame bodies (Part 5 §5.3.3).

  A SASL frame body holds exactly one described list with no trailing bytes.
  Decoding accepts numeric (`ulong 0x40`–`0x44`) and symbolic descriptors and
  retains exact tagged field values; encoding emits the numeric descriptor and
  may omit trailing absent fields. Values are bounded by the 512-octet SASL
  frame. Errors carry only the body name and field index — never field bytes,
  lengths or values. `sasl-code` is not whitelisted.
  """

  alias GravitonMQ.AMQP10.Codec.Error
  alias GravitonMQ.AMQP10.Codec.Frame, as: FrameCodec
  alias GravitonMQ.AMQP10.Codec.Limits
  alias GravitonMQ.AMQP10.Codec.Value, as: ValueCodec
  alias GravitonMQ.AMQP10.Frame
  alias GravitonMQ.AMQP10.SASL.{Challenge, Init, Mechanisms, Outcome, Response}
  alias GravitonMQ.AMQP10.Value
  alias GravitonMQ.AMQP10.Value.{Array, Described}

  @limits %Limits{
    max_frame_size: 512,
    max_value_bytes: 504,
    max_compound_items: 64,
    max_nesting_depth: 4,
    max_zero_width_elements: 64
  }
  @max_mechanisms 16
  @names %{
    0x40 => :mechanisms,
    0x41 => :init,
    0x42 => :challenge,
    0x43 => :response,
    0x44 => :outcome
  }
  @symbols %{
    "amqp:sasl-mechanisms:list" => 0x40,
    "amqp:sasl-init:list" => 0x41,
    "amqp:sasl-challenge:list" => 0x42,
    "amqp:sasl-response:list" => 0x43,
    "amqp:sasl-outcome:list" => 0x44
  }
  @counts %{0x40 => 1, 0x41 => 3, 0x42 => 1, 0x43 => 1, 0x44 => 2}

  @type body :: Mechanisms.t() | Init.t() | Challenge.t() | Response.t() | Outcome.t()

  @spec limits() :: Limits.t()
  def limits, do: @limits

  @spec decode(binary()) :: {:ok, body()} | {:error, Error.t()}
  def decode(<<>>), do: error(:sasl_decode, :malformed, :empty_sasl_frame)

  def decode(body) when is_binary(body) do
    case ValueCodec.decode(body, @limits) do
      {:ok, value, <<>>} ->
        decode_value(value)

      {:ok, _value, _rest} ->
        error(:sasl_decode, :malformed, :trailing_bytes)

      {:more, _needed} ->
        error(:sasl_decode, :malformed, :truncated_sasl_body)

      {:error, %Error{class: class, reason: reason, offset: offset}} ->
        {:error, Error.new(:sasl_decode, class, reason, offset: offset)}
    end
  end

  def decode(_body), do: error(:sasl_decode, :invalid_value, :invalid_sasl_body)

  @spec encode(body()) :: {:ok, binary()} | {:error, Error.t()}
  def encode(body) do
    with {:ok, code, fields} <- body_fields(body),
         {:ok, _body} <- validate(code, fields, :sasl_encode, :invalid_value) do
      fields =
        fields
        |> Enum.reverse()
        |> Enum.drop_while(&is_nil/1)
        |> Enum.reverse()
        |> Enum.map(&(&1 || Value.null()))

      case ValueCodec.encode(Value.described(Value.ulong(code), Value.list(fields)), @limits) do
        {:ok, bytes} -> {:ok, bytes}
        {:error, %Error{class: class, reason: reason}} -> error(:sasl_encode, class, reason)
      end
    end
  end

  @doc "Encode a body as a complete SASL frame (channel 0, data offset 2, at most 512 octets)."
  @spec encode_frame(body()) :: {:ok, binary()} | {:error, Error.t()}
  def encode_frame(body) do
    with {:ok, bytes} <- encode(body) do
      FrameCodec.encode(
        %Frame{
          declared_size: 8 + byte_size(bytes),
          data_offset_words: 2,
          type: :sasl,
          channel: 0,
          extended_header: <<>>,
          body: bytes
        },
        Limits.default(),
        types: [:sasl]
      )
    end
  end

  defp body_fields(%Mechanisms{server_mechanisms: mechanisms}), do: {:ok, 0x40, [mechanisms]}

  defp body_fields(%Init{mechanism: mechanism, initial_response: response, hostname: hostname}),
    do: {:ok, 0x41, [mechanism, response, hostname]}

  defp body_fields(%Challenge{challenge: challenge}), do: {:ok, 0x42, [challenge]}
  defp body_fields(%Response{response: response}), do: {:ok, 0x43, [response]}

  defp body_fields(%Outcome{code: code, additional_data: data}),
    do: {:ok, 0x44, [code, data]}

  defp body_fields(_body), do: error(:sasl_encode, :invalid_value, :invalid_sasl_body)

  defp decode_value(%Value{type: :described, value: %Described{descriptor: descriptor, value: body}}) do
    case {descriptor_code(descriptor), body} do
      {nil, _body} ->
        error(:sasl_decode, :malformed, :not_a_sasl_body)

      {code, %Value{type: :list, value: fields}} when is_list(fields) ->
        validate(code, fields, :sasl_decode, :malformed)

      {code, _body} ->
        error(:sasl_decode, :malformed, :invalid_sasl_body, %{body: Map.fetch!(@names, code)})
    end
  end

  defp decode_value(_value), do: error(:sasl_decode, :malformed, :not_a_sasl_body)

  defp descriptor_code(%Value{type: :ulong, value: code}) when is_map_key(@names, code), do: code

  defp descriptor_code(%Value{type: :symbol, value: symbol}) when is_map_key(@symbols, symbol),
    do: Map.fetch!(@symbols, symbol)

  defp descriptor_code(_descriptor), do: nil

  defp validate(code, fields, operation, class) do
    name = Map.fetch!(@names, code)

    if length(fields) > Map.fetch!(@counts, code),
      do: error(operation, class, :too_many_fields, %{body: name}),
      else: fields(name, fields, operation, class)
  end

  defp fields(:mechanisms, fields, operation, class) do
    case Enum.at(fields, 0) do
      %Value{type: :symbol, value: name} = value when is_binary(name) ->
        {:ok, %Mechanisms{server_mechanisms: value}}

      %Value{type: :array, value: %Array{element_type: :symbol, values: []}} ->
        field_error(operation, class, :empty_mechanism_list, :mechanisms, 0)

      %Value{type: :array, value: %Array{element_type: :symbol, values: values}} = value
      when is_list(values) ->
        cond do
          length(values) > @max_mechanisms ->
            field_error(operation, :limit_exceeded, :too_many_mechanisms, :mechanisms, 0)

          Enum.all?(values, &match?(%Value{type: :symbol, value: name} when is_binary(name), &1)) ->
            {:ok, %Mechanisms{server_mechanisms: value}}

          true ->
            field_error(operation, class, :field_type_mismatch, :mechanisms, 0)
        end

      value ->
        reason = if absent?(value), do: :mandatory_field_missing, else: :field_type_mismatch
        field_error(operation, class, reason, :mechanisms, 0)
    end
  end

  defp fields(:init, fields, operation, class) do
    with {:ok, mechanism} <- required(fields, 0, :symbol, :init, operation, class),
         {:ok, response} <- optional(fields, 1, :binary, :init, operation, class),
         {:ok, hostname} <- optional(fields, 2, :string, :init, operation, class) do
      {:ok, %Init{mechanism: mechanism, initial_response: response, hostname: hostname}}
    end
  end

  defp fields(:challenge, fields, operation, class) do
    with {:ok, challenge} <- required(fields, 0, :binary, :challenge, operation, class),
         do: {:ok, %Challenge{challenge: challenge}}
  end

  defp fields(:response, fields, operation, class) do
    with {:ok, response} <- required(fields, 0, :binary, :response, operation, class),
         do: {:ok, %Response{response: response}}
  end

  defp fields(:outcome, fields, operation, class) do
    with {:ok, code} <- required(fields, 0, :ubyte, :outcome, operation, class),
         {:ok, data} <- optional(fields, 1, :binary, :outcome, operation, class) do
      {:ok, %Outcome{code: code, additional_data: data}}
    end
  end

  defp required(fields, index, type, body, operation, class) do
    case Enum.at(fields, index) do
      %Value{type: ^type} = value ->
        {:ok, value}

      value ->
        reason = if absent?(value), do: :mandatory_field_missing, else: :field_type_mismatch
        field_error(operation, class, reason, body, index)
    end
  end

  defp optional(fields, index, type, body, operation, class) do
    case Enum.at(fields, index) do
      %Value{type: ^type} = value -> {:ok, value}
      value -> if absent?(value), do: {:ok, nil}, else: field_error(operation, class, :field_type_mismatch, body, index)
    end
  end

  defp absent?(nil), do: true
  defp absent?(%Value{type: :null}), do: true
  defp absent?(_value), do: false

  defp field_error(operation, class, reason, body, index),
    do: error(operation, class, reason, %{body: body, index: index})

  defp error(operation, class, reason, details \\ %{}),
    do: {:error, Error.new(operation, class, reason, details: details)}
end
```

```elixir
defmodule GravitonMQ.AMQP10.SASL.Plain do
  @moduledoc """
  RFC 4616 PLAIN message: `[authzid] NUL authcid NUL passwd`.

  `username` (authcid) and `password` are 1..255 octets, `authzid` 0..255
  octets (empty means absent); all are valid UTF-8 without NUL. Failures carry
  no detail. `Inspect` prints no field. The authorization identity is passed
  through; the host decides whether it is acceptable.
  """

  @enforce_keys [:username, :password]
  defstruct [:username, :password, authzid: nil]

  @type t :: %__MODULE__{username: binary(), password: binary(), authzid: binary() | nil}

  @spec new(term(), term(), term()) :: {:ok, t()} | {:error, :invalid_plain_message}
  def new(username, password, authzid \\ nil) do
    if field?(username, 1) and field?(password, 1) and (is_nil(authzid) or field?(authzid, 0)),
      do:
        {:ok,
         %__MODULE__{
           username: username,
           password: password,
           authzid: if(authzid == "", do: nil, else: authzid)
         }},
      else: {:error, :invalid_plain_message}
  end

  @spec parse(term()) :: {:ok, t()} | {:error, :invalid_plain_message}
  def parse(message) when is_binary(message) and byte_size(message) <= 767 do
    case :binary.split(message, <<0>>, [:global]) do
      [authzid, username, password] -> new(username, password, authzid)
      _other -> {:error, :invalid_plain_message}
    end
  end

  def parse(_message), do: {:error, :invalid_plain_message}

  @spec encode(t()) :: binary()
  def encode(%__MODULE__{username: username, password: password, authzid: authzid}),
    do: (authzid || "") <> <<0>> <> username <> <<0>> <> password

  defp field?(value, minimum),
    do:
      is_binary(value) and byte_size(value) >= minimum and byte_size(value) <= 255 and
        String.valid?(value) and not String.contains?(value, <<0>>)
end
```

Server state table (spec §4.2, D2, D5):

| Phase | Event | Effects → next |
| --- | --- | --- |
| `:new` | `:start` | `wake_at` (negotiation deadline) → `:await_header` |
| `:await_header` | header 3, mode ≠ disabled | send `AMQP 3 1 0 0` + sasl-mechanisms → `:await_init` |
| | header 0, mode ≠ required | `cancel_wake`, `{:established, :no_sasl}`, `{:start_endpoint, header}` → `:done` |
| | header 0, required | send `AMQP 3 1 0 0`; after its receipt `{:close, :sasl_required}` |
| | header 3, disabled | send `AMQP 0 1 0 0`; after receipt `{:close, :sasl_not_supported}` |
| | header decode error | send preferred header; after receipt `{:close, :unsupported_protocol_header}` |
| `:await_init` | valid init, offered, no callback (ANONYMOUS) | `{:expect_header, [0]}`, outcome ok bytes, `{:outcome, :ok}`, `{:established, {:sasl, :anonymous}}` → `:await_amqp_header` |
| | valid init, callback | `{:expect_header, [0]}`, `{:authenticate, ref, credentials}` → `:authenticating` |
| | not offered / invalid message | `{:outcome, :auth}`, outcome `auth`; after receipt `{:close, {:sasl, :auth}}` |
| | other body / decode error | `{:close, :sasl_protocol_error}` / `{:close, {:decode_error, reason}}` (no outcome) |
| `:authenticating` | `{:auth_result, ref, :ok}` | outcome ok, established; plus `{:start_endpoint, h}` → `:done` if a header was pipelined, else → `:await_amqp_header` |
| | `{:auth_result, ref, {:error, code}}` | `{:outcome, code}`, outcome code; after receipt `{:close, {:sasl, code}}` |
| | header 0 (pipelined) | retained |
| | anything else | `{:cancel_authentication, ref}`, `{:close, :sasl_protocol_error}` |
| `:await_amqp_header` | header 0 | `cancel_wake`, `{:start_endpoint, header}` → `:done` |
| | anything else | send `AMQP 0 1 0 0`; after receipt `{:close, :unsupported_protocol_header}` |
| any active | deadline / `transport_down` / failed write | `{:close, :sasl_timeout \| reason}` (auth cancelled first) |

```elixir
defmodule GravitonMQ.AMQP10.SASL.Machine do
  @moduledoc """
  Pure AMQP 1.0 SASL negotiation (Part 5 §5.3) for ANONYMOUS and PLAIN.

  Same contract as `GravitonMQ.AMQP10.Endpoint.step/2`: generation-fenced
  facts `%{generation, now_ms, event}` return `{state, effects}`. The machine
  owns no socket, process or clock and runs before the Endpoint; a shell steps
  the Endpoint `:start` only after `{:start_endpoint, header_or_nil}`.

  Events: `:start`, `{:header, ProtocolHeader.t()}`, `{:frame, Frame.t()}`,
  `{:decode_error, Codec.Error.t()}`, `{:write_result, {:sasl, n}, result}`,
  `{:auth_result, ref, :ok | {:error, :auth | :sys | :sys_perm | :sys_temp}}`,
  `{:timeout, :sasl_negotiation, token}` and `{:transport_down, reason}`.

  Effects: `{:send_bytes, generation, {:sasl, n}, bytes}`,
  `{:wake_at, generation, :sasl_negotiation, token, at}`,
  `{:cancel_wake, generation, :sasl_negotiation, token}`, `{:expect_header, [0]}`,
  `{:authenticate, ref, credentials}`, `{:cancel_authentication, ref}`,
  `{:outcome, code_name}`, `{:established, :no_sasl | {:sasl, mechanism}}`,
  `{:start_endpoint, ProtocolHeader.t() | nil}` and `{:close, reason}`.

  A server never stores credentials: they leave only inside
  `{:authenticate, ...}`, and the principal stays in the shell. A client drops
  its credentials once sasl-init is emitted. Final refusal bytes (a protocol
  header or a failing sasl-outcome) are flushed before `{:close, reason}`;
  protocol violations close without an outcome. ANONYMOUS and PLAIN are
  single-step, so a challenge or response is a protocol error.
  """

  alias GravitonMQ.AMQP10.{Frame, SASL, Value}
  alias GravitonMQ.AMQP10.Codec.{Error, ProtocolHeader}
  alias GravitonMQ.AMQP10.Codec.SASL, as: SASLCodec
  alias GravitonMQ.AMQP10.SASL.{Anonymous, Init, Mechanisms, Outcome, Plain}

  @sasl_header <<"AMQP", 3, 1, 0, 0>>
  @amqp_header <<"AMQP", 0, 1, 0, 0>>
  @deadline :sasl_negotiation
  @failure_codes [:auth, :sys, :sys_perm, :sys_temp]

  defstruct [
    :role,
    :mode,
    :mechanisms,
    :authenticate,
    :credentials,
    :hostname,
    :timeout_ms,
    generation: 0,
    phase: :new,
    now_ms: nil,
    next_write: 0,
    next_token: 0,
    next_auth: 0,
    deadline: nil,
    closing: nil,
    auth: nil,
    mechanism: nil,
    early_header: nil
  ]

  @type t :: %__MODULE__{}

  @spec new(keyword()) :: {:ok, t()} | {:error, :invalid_options}
  def new(options) when is_list(options) do
    if Keyword.keyword?(options), do: build(Map.new(options)), else: {:error, :invalid_options}
  end

  def new(_options), do: {:error, :invalid_options}

  @doc "True until the AMQP layer owns input (`:done`) or negotiation closed."
  @spec active?(t()) :: boolean()
  def active?(%__MODULE__{phase: phase}), do: phase not in [:done, :closed]

  @doc "Timer key used for the negotiation deadline in wake effects."
  @spec deadline_key() :: :sasl_negotiation
  def deadline_key, do: @deadline

  defp build(%{role: :server} = options) do
    state = %__MODULE__{
      role: :server,
      mode: Map.get(options, :mode, :optional),
      mechanisms: Map.get(options, :mechanisms, [SASL.anonymous()]),
      authenticate: Map.get(options, :authenticate, false),
      timeout_ms: Map.get(options, :timeout_ms),
      generation: Map.get(options, :generation, 0)
    }

    cond do
      not common_valid?(state) -> {:error, :invalid_options}
      state.mode not in [:optional, :required, :disabled] -> {:error, :invalid_options}
      not is_boolean(state.authenticate) -> {:error, :invalid_options}
      state.mode != :disabled and not mechanisms_valid?(state) -> {:error, :invalid_options}
      true -> {:ok, state}
    end
  end

  defp build(_options), do: {:error, :invalid_options}

  defp common_valid?(state),
    do:
      is_integer(state.timeout_ms) and state.timeout_ms > 0 and is_integer(state.generation) and
        state.generation >= 0

  defp mechanisms_valid?(%{mechanisms: mechanisms, authenticate: authenticate}) do
    is_list(mechanisms) and mechanisms != [] and Enum.uniq(mechanisms) == mechanisms and
      Enum.all?(mechanisms, &(&1 in SASL.supported_mechanisms())) and
      (authenticate or SASL.plain() not in mechanisms)
  end

  @spec step(t(), map()) :: {t(), list()}
  def step(
        %__MODULE__{generation: generation} = state,
        %{generation: generation, now_ms: now, event: event}
      )
      when is_integer(now) do
    if is_integer(state.now_ms) and now < state.now_ms,
      do: {state, []},
      else: dispatch(%{state | now_ms: now}, event)

  def step(%__MODULE__{} = state, _facts), do: {state, []}

  # Common fences.
  defp dispatch(%{phase: phase} = state, _event) when phase in [:done, :closed], do: {state, []}
  defp dispatch(state, {:transport_down, reason}), do: close(state, reason)

  defp dispatch(%{deadline: {token, _at}} = state, {:timeout, @deadline, token}),
    do: close(%{state | deadline: nil}, :sasl_timeout)

  defp dispatch(state, {:timeout, _key, _token}), do: {state, []}
  defp dispatch(%{closing: {id, reason}} = state, {:write_result, id, _result}), do: close(state, reason)
  defp dispatch(%{closing: {_id, _reason}} = state, _event), do: {state, []}
  defp dispatch(state, {:write_result, _id, :ok}), do: {state, []}
  defp dispatch(state, {:write_result, _id, {:error, reason}}), do: close(state, reason)

  # Server role.
  defp dispatch(%{role: :server, phase: :new} = state, :start) do
    {state, wake} = set_deadline(state)
    {%{state | phase: :await_header}, wake}
  end

  defp dispatch(%{role: :server, phase: :await_header} = state, {:header, %ProtocolHeader{protocol_id: 3}}) do

      fail(state, :sasl_not_supported, @amqp_header)
    else
      {:ok, frame} = SASLCodec.encode_frame(%Mechanisms{server_mechanisms: mechanism_list(state)})
      {state, _id, sent} = send_bytes(state, @sasl_header <> frame)
      {%{state | phase: :await_init}, sent}
    end
  end

  defp dispatch(%{role: :server, phase: :await_header} = state, {:header, %ProtocolHeader{protocol_id: 0} = header}) do
    if state.mode == :required do
      fail(state, :sasl_required, @sasl_header)
    else
      {state, cancel} = cancel_deadline(state)
      {%{state | phase: :done}, cancel ++ [{:established, :no_sasl}, {:start_endpoint, header}]}
    end
  end

  defp dispatch(%{role: :server, phase: :await_header} = state, {:decode_error, %Error{operation: :protocol_header}}),
    do: fail(state, :unsupported_protocol_header, preferred_header(state))

  defp dispatch(%{role: :server, phase: :await_init} = state, {:frame, %Frame{type: :sasl, body: body}}) do
    case SASLCodec.decode(body) do
      {:ok, %Init{} = init} -> init(state, init)
      {:ok, _other} -> close(state, :sasl_protocol_error)
      {:error, %Error{reason: reason}} -> close(state, {:decode_error, reason})
    end
  end

    do: succeed(%{state | auth: nil}, [])

  defp dispatch(%{role: :server, phase: :authenticating, auth: ref} = state, {:auth_result, ref, {:error, code}})
       when code in @failure_codes,
       do: outcome_failure(%{state | auth: nil}, code)

         %{role: :server, phase: :authenticating, early_header: nil} = state,

       ),

  defp dispatch(%{role: :server, phase: :await_amqp_header} = state, {:header, %ProtocolHeader{protocol_id: 0} = header}) do
    {state, cancel} = cancel_deadline(state)
    {%{state | phase: :done}, cancel ++ [{:start_endpoint, header}]}
  end

  # Fallbacks shared by both roles.
  defp dispatch(state, :start), do: {state, []}
  defp dispatch(state, {:auth_result, _ref, _result}), do: {state, []}
  defp dispatch(%{phase: :authenticating} = state, _event), do: close(state, :sasl_protocol_error)

  defp dispatch(%{role: :server, phase: :await_amqp_header} = state, _event),
    do: fail(state, :unsupported_protocol_header, @amqp_header)

  defp dispatch(state, {:decode_error, %Error{reason: reason}}), do: close(state, {:decode_error, reason})
  defp dispatch(state, _event), do: close(state, :sasl_protocol_error)

  defp init(state, %Init{mechanism: %Value{value: name}} = init) do
    cond do
      name not in state.mechanisms -> outcome_failure(state, :auth)
      name == SASL.anonymous() -> anonymous(state, init)
      true -> plain(state, init)
    end
  end

  defp anonymous(state, init) do
    case Anonymous.parse(binary_value(init.initial_response)) do
      {:ok, trace} when state.authenticate ->
        authenticate(state, :anonymous, %{
          mechanism: :anonymous,
          username: nil,
          password: nil,
          authzid: nil,
          trace: trace,
          hostname: string_value(init.hostname)
        })

      {:ok, _trace} ->
        succeed(%{state | mechanism: :anonymous}, [{:expect_header, [0]}])

      {:error, _reason} ->
        outcome_failure(state, :auth)
    end
  end

  defp plain(state, %Init{initial_response: %Value{type: :binary, value: message}} = init) do
    case Plain.parse(message) do
      {:ok, plain} ->
        authenticate(state, :plain, %{
          mechanism: :plain,
          username: plain.username,
          password: plain.password,
          authzid: plain.authzid,
          trace: nil,
          hostname: string_value(init.hostname)
        })

      {:error, _reason} ->
        outcome_failure(state, :auth)
    end
  end

  defp plain(state, _init), do: outcome_failure(state, :auth)

  defp authenticate(state, mechanism, credentials) do
    ref = {:sasl_auth, state.next_auth}

    {%{state | phase: :authenticating, auth: ref, mechanism: mechanism, next_auth: state.next_auth + 1},
     [{:expect_header, [0]}, {:authenticate, ref, credentials}]}
  end

  defp succeed(state, prefix) do
    {:ok, frame} = SASLCodec.encode_frame(%Outcome{code: Value.ubyte(0)})
    {state, _id, sent} = send_bytes(state, frame)
    established = [{:outcome, :ok}, {:established, {:sasl, state.mechanism}}]

    case state.early_header do
      nil ->
        {%{state | phase: :await_amqp_header}, prefix ++ sent ++ established}

      header ->
        {state, cancel} = cancel_deadline(state)

        {%{state | phase: :done, early_header: nil},
         prefix ++ sent ++ established ++ cancel ++ [{:start_endpoint, header}]}
    end
  end

  defp outcome_failure(state, code) do
    {:ok, frame} = SASLCodec.encode_frame(%Outcome{code: Value.ubyte(SASL.code(code))})
    {state, effects} = fail(state, {:sasl, code}, frame)
    {state, [{:outcome, code} | effects]}
  end

  defp fail(state, reason, bytes) do
    {state, cancel} = cancel_auth(state)
    {state, id, sent} = send_bytes(state, bytes)
    {%{state | closing: {id, reason}}, cancel ++ sent}
  end

  defp close(state, reason) do
    {state, cancel_auth} = cancel_auth(state)
    {state, cancel} = cancel_deadline(state)

    {%{state | phase: :closed, closing: nil, credentials: nil, early_header: nil},
     cancel_auth ++ cancel ++ [{:close, reason}]}
  end

  defp mechanism_list(%{mechanisms: [one]}), do: Value.symbol(one)
  defp mechanism_list(%{mechanisms: many}), do: Value.array(:symbol, Enum.map(many, &Value.symbol/1))

  defp preferred_header(%{mode: :required}), do: @sasl_header
  defp preferred_header(_state), do: @amqp_header

  defp send_bytes(state, bytes) do
    id = {:sasl, state.next_write}
    {%{state | next_write: state.next_write + 1}, id, [{:send_bytes, state.generation, id, bytes}]}
  end

  defp set_deadline(state) do
    token = state.next_token
    at = state.now_ms + state.timeout_ms

    {%{state | next_token: token + 1, deadline: {token, at}},
     [{:wake_at, state.generation, @deadline, token, at}]}
  end

  defp cancel_deadline(%{deadline: nil} = state), do: {state, []}

  defp cancel_deadline(%{deadline: {token, _at}} = state),
    do: {%{state | deadline: nil}, [{:cancel_wake, state.generation, @deadline, token}]}

  defp cancel_auth(%{auth: nil} = state), do: {state, []}
  defp cancel_auth(%{auth: ref} = state), do: {%{state | auth: nil}, [{:cancel_authentication, ref}]}

  defp binary_value(nil), do: nil
  defp binary_value(%Value{type: :binary, value: value}), do: value
  defp string_value(nil), do: nil
  defp string_value(%Value{type: :string, value: value}), do: value
end
```

```elixir
defmodule GravitonMQ.Runtime.AMQP10.Auth do
  @moduledoc """
  Host authentication policy for AMQP 1.0 SASL on the broker.

  Configure `amqp10: [auth: {module, options}]`. The broker invokes
  `c:authenticate/2` in a temporary supervised task, outside protocol
  transitions, bounded by `max_sasl_jobs` and `auth_timeout`. Credentials are

      %{mechanism: :plain | :anonymous, username, password, authzid, trace,
        hostname, peer: %{ip, port, transport, certificate, certificate_verified}}

  (`nil` where a mechanism has no such field). The callback owns credential
  verification — use a constant-time comparison — and the `authzid` policy.
  The returned principal becomes the first argument of `authorize/3`.
  `{:error, _}` refuses with sasl-outcome `auth`; an invalid return,
  exception or exit refuses with `sys`; a missed deadline or exhausted
  concurrency refuses with `sys-temp`. Callback reasons are never logged,
  reported to the peer or returned.
  """

  @callback authenticate(credentials :: map(), options :: keyword()) ::
              {:ok, principal :: term()} | {:error, term()}

  @doc false
  @spec invoke(module(), keyword(), map()) :: {:ok, term()} | {:error, :auth | :sys}
  def invoke(module, options, credentials) do
    case module.authenticate(credentials, options) do
      {:ok, principal} -> {:ok, principal}
      {:error, _reason} -> {:error, :auth}
      _invalid -> {:error, :sys}
    end
  catch
    _kind, _reason -> {:error, :sys}
  end

  @doc false
  # Supervises the actual callback so a slot cannot outlive its deadline or
  # its Connection, even if the callback traps ordinary exits.
  @spec watch(pid(), pid(), integer()) :: :ok | true
  def watch(callback, caller, deadline) do
    callback_monitor = Process.monitor(callback)
    caller_monitor = Process.monitor(caller)

    receive do
      {:DOWN, ^callback_monitor, :process, ^callback, _reason} -> :ok
      {:DOWN, ^caller_monitor, :process, ^caller, _reason} -> Process.exit(callback, :kill)
    after
      max(deadline - System.monotonic_time(:millisecond), 0) -> Process.exit(callback, :kill)
    end
  end
end
```

```elixir
  defp authentication(options) do
    case Keyword.get(options, :auth) do
      :anonymous ->
        {:ok, :anonymous}

      nil ->
        {:error, :explicit_auth_required}

      {module, auth_options} when is_atom(module) and is_list(auth_options) ->
        if Keyword.keyword?(auth_options) and Code.ensure_loaded?(module) and
             function_exported?(module, :authenticate, 2),
           do: {:ok, {module, auth_options}},
           else: {:error, :unsupported_authentication}

      _other ->
        {:error, :unsupported_authentication}
    end
  end

  # The SASL map is published to Connections; it never contains the policy.
  defp sasl(options, policy, config) do
    authenticate = policy != :anonymous
    mode = Keyword.get(options, :sasl, if(authenticate, do: :required, else: :optional))

    mechanisms =
      Keyword.get(options, :sasl_mechanisms, if(authenticate, do: ["PLAIN"], else: ["ANONYMOUS"]))

    insecure = Keyword.get(options, :allow_insecure_plain, false)
    timeout = Keyword.get(options, :sasl_timeout, 5_000)
    jobs = Keyword.get(options, :max_sasl_jobs, 16)

    cond do
      mode not in [:optional, :required, :disabled] ->
        {:error, :invalid_options}

      authenticate and mode != :required ->
        {:error, :sasl_required_for_authentication}

      not is_list(mechanisms) or mechanisms == [] or Enum.uniq(mechanisms) != mechanisms or
          not Enum.all?(mechanisms, &(&1 in ["PLAIN", "ANONYMOUS"])) ->
        {:error, :invalid_sasl_mechanisms}

      "PLAIN" in mechanisms and not authenticate ->
        {:error, :plain_requires_authentication}

      not is_boolean(insecure) or not bounded?(timeout, 1, 10_000) or not bounded?(jobs, 1, 128) ->
        {:error, :invalid_options}

      true ->
        {:ok,
         %{
           mode: mode,
           mechanisms: mechanisms,
           authenticate: authenticate,
           allow_insecure_plain: insecure,
           timeout: timeout,
           max_jobs: jobs,
           auth_timeout: config.auth_timeout
         }}
    end
  end

  defp plain_transport(%{mode: :disabled}, _listeners), do: :ok

  defp plain_transport(sasl, listeners) do
    if "PLAIN" in sasl.mechanisms and not sasl.allow_insecure_plain and
         Enum.any?(listeners, &(&1.transport == :tcp)),
       do: {:error, :plain_requires_tls},
       else: :ok
  end
```

```elixir
defmodule GravitonMQ.Runtime.AMQP10.Authenticator do
  @moduledoc false
  # Holds the host authentication policy outside every published Connection
  # specification (Listener's ETS spec is readable by any process) and starts
  # each callback as a temporary child of `:sasl_tasks`. Credentials pass
  # through this sensitive process only as call arguments and are never
  # stored in its state; temporary Task.Supervisor children do not retain
  # their start arguments. The Broker/Manager never sees credentials.
  use GenServer

  alias GravitonMQ.Runtime.AMQP10.Auth

  @call_timeout 1_000

  def start_link(configuration), do: GenServer.start_link(__MODULE__, configuration)

  def child_spec(configuration),
    do: %{id: __MODULE__, start: {__MODULE__, :start_link, [fn -> configuration end]}}

  @spec start(pid() | nil, map(), pid(), term(), pos_integer()) ::
          {:ok, pid()} | {:error, :busy | :unavailable}
  def start(nil, _credentials, _reply_to, _reference, _timeout), do: {:error, :unavailable}

  def start(authenticator, credentials, reply_to, reference, timeout) do
    GenServer.call(
      authenticator,
      {:start, credentials, reply_to, reference, timeout},
      @call_timeout
    )
  catch
    :exit, _reason -> {:error, :unavailable}
  end

  @impl true
  def init(configuration) do
    Process.flag(:sensitive, true)
    {policy, parent} = configuration.()
    {:ok, %{policy: policy, parent: parent, tasks: nil}, {:continue, :wire}}
  end

  @impl true
  def handle_continue(:wire, state) do
    {_, tasks, _, _} = List.keyfind(Supervisor.which_children(state.parent), :sasl_tasks, 0)
    {:noreply, %{state | tasks: tasks}}
  end

  @impl true
  def handle_call(
        {:start, credentials, reply_to, reference, timeout},
        _from,
        %{policy: {module, options}, tasks: tasks} = state
      )
      when is_pid(tasks) and is_pid(reply_to) and is_integer(timeout) and timeout > 0 do
    deadline = System.monotonic_time(:millisecond) + timeout

    callback = fn ->
      Process.flag(:sensitive, true)
      task = self()
      spawn(fn -> Auth.watch(task, reply_to, deadline) end)
      send(reply_to, {:amqp10_sasl_result, reference, Auth.invoke(module, options, credentials)})
    end

    reply =
      try do
        case Task.Supervisor.start_child(tasks, callback) do
          {:ok, pid} -> {:ok, pid}
          {:error, :max_children} -> {:error, :busy}
          _other -> {:error, :unavailable}
        end
      catch
        :exit, _reason -> {:error, :unavailable}
      end

    {:reply, reply, state}
  end

  def handle_call(_request, _from, state), do: {:reply, {:error, :unavailable}, state}

  @impl true
  def format_status(status),
    do: Map.merge(status, %{state: :redacted, message: :redacted, reason: :redacted, log: []})
end
```

```python
"""Independent Qpid Proton 0.40.0 SASL client used against the Graviton broker.

The Graviton client is never imported here. Commands terminate with a finite
timeout, print JSON without credentials and report content digests.
"""
import argparse
import hashlib
import inspect
import json
import sys
from pathlib import Path

import proton
import proton.reactor
from proton import Message, SSLDomain
from proton.reactor import AtLeastOnce
from proton.utils import BlockingConnection

KEYWORDS = ("sasl_enabled", "allowed_mechs", "allow_insecure_mechs", "user", "password")


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("operation", choices=["send", "receive"])
    parser.add_argument("url")
    parser.add_argument("address")
    parser.add_argument("path")
    parser.add_argument("--no-sasl", action="store_true")
    parser.add_argument("--mechs")
    parser.add_argument("--user")
    parser.add_argument("--password")
    parser.add_argument("--insecure", action="store_true")
    parser.add_argument("--cafile")
    arguments = parser.parse_args()
    version = ".".join(str(value) for value in proton.VERSION)
    if version != "0.40.0":
        raise RuntimeError(f"Expected Qpid Proton 0.40.0, got {version}")
    source = inspect.getsource(proton.reactor)
    missing = [keyword for keyword in KEYWORDS if keyword not in source]
    if missing:
        raise RuntimeError(f"Proton connect keywords unavailable: {missing}")
    options = {"sasl_enabled": not arguments.no_sasl}
    if arguments.mechs:
        options["allowed_mechs"] = arguments.mechs
    if arguments.user is not None:
        options["user"] = arguments.user
    if arguments.password is not None:
        options["password"] = arguments.password
    if arguments.insecure:
        options["allow_insecure_mechs"] = True
    ssl_domain = None
    if arguments.cafile:
        ssl_domain = SSLDomain(SSLDomain.MODE_CLIENT)
        ssl_domain.set_trusted_ca_db(arguments.cafile)
        ssl_domain.set_peer_authentication(SSLDomain.VERIFY_PEER_NAME)
    try:
        connection = BlockingConnection(arguments.url, timeout=10, ssl_domain=ssl_domain, **options)
    except Exception as error:  # refused authentication surfaces here
        print(json.dumps({"connected": False, "error": type(error).__name__}), flush=True)
        return 3
    try:
        if arguments.operation == "send":
            body = Path(arguments.path).read_bytes()
            sender = connection.create_sender(arguments.address, options=AtLeastOnce())
            sender.send(Message(body=body), timeout=10)
            print(json.dumps({"sent_bytes": len(body), "sha256": hashlib.sha256(body).hexdigest()}), flush=True)
        else:
            receiver = connection.create_receiver(arguments.address, credit=1, options=AtLeastOnce())
            print(json.dumps({"ready": True}), flush=True)
            message = receiver.receive(timeout=10)
            body = bytes(message.body)
            receiver.accept()
            print(json.dumps({"received_bytes": len(body), "sha256": hashlib.sha256(body).hexdigest()}), flush=True)
    except Exception as error:
        print(json.dumps({"failed": type(error).__name__}), flush=True)
        return 4
    finally:
        connection.close()
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
